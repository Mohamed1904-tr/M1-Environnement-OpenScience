## Thème environnemental
Impact de la température sur l'alimentation et la santé humaine.

## Objectif de l'analyse
Analyser des données météorologiques avec Python (pandas, matplotlib) afin
d'étudier l'effet de la température sur la conservation des aliments, les
intoxications alimentaires et la santé humaine, dans une démarche d'Open
Science et de reproductibilité
## Données
Fichier `data/donnees_meteo.csv` : 90 observations journalières (juin à août 2025) avec trois variables : `Date`, `Temperature` (°C) et `Precipitation` (mm).

## Outils
- Python (pandas, matplotlib)
- Jupyter Notebook / Google Colab
- Git et GitHub

## Structure du projet
- `data/` : données météorologiques
- `notebooks/` : notebook d'analyse (`analyse_meteo.ipynb`)
- `results/` : résultats

## Comment reproduire l'analyse
1. Télécharger ou cloner ce dépôt.
2. Ouvrir `notebooks/analyse_meteo.ipynb` dans Jupyter ou Google Colab.
3. Exécuter toutes les cellules.
4. Vérifier que les résultats et les graphiques s'affichent.
